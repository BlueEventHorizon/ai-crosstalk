# FNC-015 宛先解決 要件定義書

## メタデータ

| 項目     | 値                          |
| -------- | --------------------------- |
| 要件ID   | FNC-015                     |
| 関連要件 | APP-003 / FNC-014 / FNC-016 |

## 概要

ユーザーが自然語で指定した相手から、送信時点で実在する送り先を 1 つに決める。用語は APP-003「用語」に従う。

## 前提条件

- 通信路が FNC-014 で判定済みである

## 要件一覧

### 指定

- ユーザーは自然語で相手を指定する
- herdr / Orca では、リポジトリ・worktree・エージェント種別で指定する（herdr では worktree を作業ディレクトリのパスで表す）。セッション名・端末番号・タイトルは作業内容や再起動で変わるため、宛先の軸にしない
- CSM では、セッション名で指定する（CSM は相手の worktree・エージェント種別を返さないため）

### 解決

- 宛先解決は送信のたびに行う。以前の解決結果を再利用しない
- 同じ環境・同じ指定に対しては、同じ解決結果になる
- 自分自身は宛先の候補にしない
- リポジトリに紐づかない worktree（一時ディレクトリに作られたもの等）は宛先の候補にしない
- 候補が 1 件のときだけ、その候補を宛先とする

### 解決結果

解決結果は次を含み、FNC-016 の承認の材料としてユーザーに提示される。

- 通信路
- 通信路が取得できる範囲の、宛先を特定する情報。取得できないものは、取得できないことを示して省略する
  - Orca: リポジトリ、worktree、ブランチ、エージェント種別
  - herdr: 作業ディレクトリ、pane、エージェント種別（ブランチとリポジトリ名は取得できない）
  - CSM: セッション名

### CSM の候補からの提案

herdr / Orca で相手を確定できないとき（候補が 0 件のとき、または複数で決められないとき）、またはユーザーが CSM を使うと明示したときは、CSM が使えるなら、CSM の候補（セッション名）から相手を決める。

- CSM の候補には、作業ディレクトリなどの情報が無く、セッション名も変わりうる（番号が付き、一覧を取るたびに違うことがある）。名前との対応はすべて推定である
- ユーザーの指定が 1 つのセッションを指すときは、AI が名前との対応を鑑定して最適な候補を選び、「これですか」と確認する。提案には、選んだ理由（名前の一致など）と、根拠がセッション名だけで作業ディレクトリは確認できないことを添える
- 指定が手がかりにならないとき、または複数に当てはまるときは、AI は推測せず、候補を一覧にして「どれですか」とユーザーに尋ねる
- 確認の際は、送ろうとしている内容を添える。ユーザーが答えたときに限り、送信の手続き（FNC-016）に進む
- 提案は送信ではない。ユーザーの承認なしに、提案した相手へ送信しない

## エラーケース

| 条件              | 動作                                                                                                                   |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 宛先の候補が 0 件 | 送信しない。CSM が使えるときは、CSM の候補から相手を提案する。使えないときは、該当する相手が見つからないことを報告する |
| 宛先の候補が複数  | 送信しない。候補を提示し、最適と思われる候補を理由とともに提案して、ユーザーに選ばせる                                 |
