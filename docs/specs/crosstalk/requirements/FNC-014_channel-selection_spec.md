# FNC-014 通信路の判定 要件定義書

## メタデータ

| 項目     | 値                                    |
| -------- | ------------------------------------- |
| 要件ID   | FNC-014                               |
| 関連要件 | APP-003 / FNC-015 / FNC-016 / FNC-017 |

## 概要

送信側の実行環境から、その環境で使う通信路（herdr / Orca / CSM）を 1 つ決める。ユーザーは通信路を意識せず、相手と内容だけを指示すればよい。用語は APP-003「用語」に従う。

## 前提条件

- 送信側は Claude Code のセッションである
- herdr と Orca は同時に有効にならない

## 要件一覧

### 判定

判定は送信側の実行環境だけで行い、ユーザーの指示内容には依存しない（ユーザーが CSM を使うと明示したときを除く。下記）。次の表の上から順に判定する。

| 条件                                                                      | 使う通信路 | 相手にできるもの             |
| ------------------------------------------------------------------------- | ---------- | ---------------------------- |
| 送信側が herdr の管理下で動いており、herdr に接続できる                   | herdr      | herdr 管理下のエージェント   |
| 送信側が Orca の管理下で動いており、Orca に接続できる                     | Orca       | Orca 管理下のエージェント    |
| 上記のいずれでもなく、CSM が使える（`ListAgents` / `SendMessage` がある） | CSM        | Claude Code のセッションのみ |
| 上記のいずれでもない                                                      | なし       | なし（送信しない）           |

- 「接続できる」とは、管理ツールの実行基盤に実際に接続できることをいう。管理ツールの環境変数が存在するだけでは有効とみなさない
- 判定は通信のたびに行う。以前の判定結果を再利用しない
- 通信路の順序は、herdr / Orca、次に CSM とする
- herdr / Orca で相手を確定できないとき（FNC-015）は、CSM が使えるなら、CSM の候補から最適な相手を AI が鑑定し、ユーザーに提案する（FNC-015「CSM の候補からの提案」）。提案は送信ではなく、送信は FNC-016 の承認を経て行う
- ユーザーが CSM を使うと明示したときは、herdr / Orca の有無にかかわらず、CSM が使えるなら CSM を使う（相手は FNC-015「CSM の候補からの提案」で決める）。通信路を意識しなくてよいのは、ユーザーが指定しないときの既定である
- 相手が確定しないまま、別の通信路へ自動で送信しない

### ユーザーへの提示

- 判定した通信路を、宛先の解決結果（FNC-015）とあわせてユーザーに提示する（FNC-016 の承認の材料になる）

## エラーケース

| 条件               | 動作                                                                  |
| ------------------ | --------------------------------------------------------------------- |
| 使える通信路が無い | 送信しない。herdr / Orca の管理下でなく、CSM も使えないことを報告する |
